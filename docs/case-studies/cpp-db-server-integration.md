# C++ DB 서버와 Unity 연동

## 필요했던 이유

Unity 게임에서 사용자 계정, 랭킹과 플레이 기록을 중앙에서 관리하고 외부 네트워크를 통해 접근할 수 있는 서버가 필요했습니다. 제 역할은 저수준 네트워크 라이브러리를 새로 만드는 것이 아니라, 기존 C++ 서버의 요청 분기와 데이터 전달 흐름을 읽고 Unity의 요청·응답 라이프사이클에 맞춰 연결하는 일이었습니다.

## 기반 기술과 경계

네트워크 계층은 Unity 서버에 사용되는 공개 오픈소스 HNetwork를 활용했습니다. HNetwork 자체를 개발한 것이 아니며, 제공 API를 이용해 Unity 클라이언트와 서버·DB 사이의 응용 로직을 구성한 것이 개인 기여입니다.

## 해결 과정

- Unity 클라이언트 요청이 서버 패킷 처리 흐름과 DB 작업으로 이어지는 경로를 단계별로 추적해 연결했습니다.
- 로그인, 사용자 확인, 계정, 랭킹과 플레이 기록 요청을 DB 기능으로 연결했습니다.
- 수신 작업을 큐에 넣고 워커 스레드가 처리하는 구조를 구성했습니다.
- ODBC 연결 풀을 이용해 DB 연결을 재사용하도록 구현했습니다.
- 원격 서버 환경에서 Unity 게임이 필요한 기능에 접근할 수 있도록 연동했습니다.

초기 로직을 구현한 뒤 상급자가 코드를 다시 다듬었으므로 최종 코드 전체를 단독 구현으로 표현하지 않습니다. 이 작업을 통해 모호한 상태에서 구조를 추측하기보다, 요청이 직렬화되어 전달되고 응답이 Unity 상태와 UI에 반영되는 경계를 따라가며 원인 범위를 좁히는 방식을 익혔습니다.

## 결과

Unity 게임의 계정, 랭킹과 플레이 기록 기능을 외부 C++ 서버 및 DB와 연결하는 기반을 마련했습니다. 출시·납품·상시 운영으로 이어진 프로젝트는 아니므로 운영 성과로 표현하지 않습니다.

## 공개 제한

원본 서버에는 실제 자격 증명, DB 테이블과 필드, 내부 패킷 번호 및 회사용 데이터 구조가 포함되어 있어 코드를 공개하지 않습니다. 또한 원본 구현에는 보안상 재검토가 필요한 문자열 기반 쿼리가 있으므로 공개 데모가 필요할 경우 매개변수화된 쿼리를 사용하는 별도 예제로 새로 작성합니다.
