# BLE 장치 설정 및 실시간 입력 진단

## 필요했던 이유

전용 입력 장치를 사용하는 게임에서는 BLE 연결 여부뿐 아니라 각 입력 위치의 센서가 정상적으로 동작하는지도 실행 전에 확인해야 했습니다. 단순 연결 코드만으로는 연결 실패와 개별 센서 입력 문제를 구분하기 어려웠고, 격투게임과 리듬게임이 사용하는 입력 범위도 달랐습니다.

## 기존 조건

- BLE 저수준 통신은 Unity Asset Store 플러그인을 사용했습니다.
- 기본적인 사내 연결 코드를 인계받았습니다.
- 인계받은 코드를 단순 호출하는 수준이 아니라 실제 빌드 앱과 연결 씬에서 안정적으로 동작하도록 수정·확장할 필요가 있었습니다.

## 해결 과정

- 검색된 장치를 목록 UI에 동적으로 표시하고 중복 장치를 걸러냈습니다.
- 장치 선택, 연결·해제, characteristic 구독·해제 흐름을 연결했습니다.
- 재검색 과정에서 기존 연결 상태가 안전하게 정리된 뒤 다시 탐색하도록 흐름을 구성했습니다.
- 연결 및 구독 상태를 UI가 관찰할 수 있도록 상태 전달 구조를 확장했습니다.
- 정상 연결 상태는 초록색으로, 타격 입력이 수신된 위치는 빨간색 점멸로 표시했습니다.
- 게임별로 사용하는 입력 채널 범위에 맞춰 진단 화면을 구성했습니다.

## 결과

사용자는 게임에 진입하기 전에 장치 검색부터 연결, 데이터 구독, 위치별 센서 입력까지 한 화면에서 확인할 수 있게 됐습니다. 통신 문제와 개별 입력 문제를 시각적으로 구분할 수 있는 현장 진단 수단을 제공했습니다.

정량적인 장애 감소율이나 점검 시간은 측정하지 않았으므로 수치 성과로 표현하지 않습니다.

## 개인 기여

- BLE 연결 씬 UI와 필요한 기능 전체 구현
- 기존 사내 연결 코드의 빌드 환경 대응 및 기능 확장
- 장치 목록, 현재 장치와 연결·구독 상태 관리
- UI 상태 표현과 입력 위치 점등
- 게임별 입력 범위 연결

## 공개 범위

실제 제품명, 장치명, MAC 주소, Service/Characteristic UUID, 패킷 접두어와 입력 번호 규칙은 공개하지 않습니다. 공개 데모는 가상 장치와 의미 없는 테스트 입력으로 재구성합니다.
