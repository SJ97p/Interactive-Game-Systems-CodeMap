# Interactive Game Systems Code Map

하나의 실물 타격 장치를 카메라 포즈 인식 기반 격투와 리듬 플레이에 연결한 체감형 게임 시스템 프로젝트입니다.

## 프로젝트 개요

| 항목 | 포트폴리오 표기 |
|---|---|
| 프로젝트 | Interactive Game Systems |
| 장르 | 실물 타격 장치·카메라 포즈 인식 기반 체감형 격투·리듬게임 |
| 기간 | 2024.07 ~ 2025.02 |
| 인원 | 4인 팀 프로젝트 · 디자인 1인 포함 |
| 역할 | Unity 클라이언트 개발 / BPM 채보 도구, BLE 연결·진단 UI, MediaPipe 데이터 브리지 및 게임 서버 연동 |
| 엔진·언어 | Unity / C# / JavaScript / Node.js / C++ |
| 핵심 기술 | Unity EditorWindow, Photon, BLE, MediaPipe, JSON, UDP·TCP, Node.js·Express, ODBC·Database |
| 직접 구현·재구성 | BPM 채보 제작·인게임 스폰, BLE 검색·연결·구독·재연결 및 6개 입력 시각화, 관절 좌표 가공·스케일 조정·UDP 전달, Unity–서버 API 연동 |

<details>
<summary>공개 범위</summary>

실제 회사명·프로젝트명·장치 식별자·전용 프로토콜·원본 소스는 공개하지 않습니다. CodeMap에는 설계 흐름, 공개용 예제와 재구성한 데모를 담았습니다. Photon 사례에는 공개를 확인받은 실행 화면을 추가했으며, 회사·제품명이 표시된 상단 창 제목줄만 잘랐습니다.
